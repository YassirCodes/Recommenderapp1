# Anime Recommender System

## Overview
The **Anime Recommender System** is a personalized recommendation platform that suggests anime based on user preferences. It leverages content-based filtering with various Natural Language Processing (NLP) models, including **GloVe, Word2Vec, and Transformer models**, to deliver highly customized recommendations.

## Features
- **Personalized Recommendations**: Users receive anime suggestions based on their viewing history and preferences.
- **Multiple NLP Models**: Supports **GloVe, Word2Vec, and Transformer models**, allowing users to choose the best-suited approach for their needs.
- **Customizable Results**: Users can select their preferred recommendation model for tailored results.
- **Efficient Content-Based Filtering**: Utilizes text embeddings and similarity measures to find the most relevant anime.

## Models Used
1. **GloVe (Global Vectors for Word Representation)**: Captures word relationships based on co-occurrence statistics.
2. **Word2Vec**: Uses neural networks to create word embeddings, capturing contextual similarities.
3. **Transformer Models**: Utilizes advanced deep learning architectures for enhanced semantic understanding.


## Usage
1. Select a recommendation model from the available options (GloVe, Word2Vec, Transformer).
2. Enter anime preferences or provide a list of watched anime.
3. The system will generate a list of recommended anime tailored to the selected model.
